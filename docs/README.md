# Documentação

- `data_model.md`: tabelas da camada stage.
- `warehouse_model.md`: dimensões, fatos e regras do warehouse.

  calculada por `dim_season.is_completed`.
- `manual_data_corrections.md`: correções persistentes complementadas
  manualmente.
